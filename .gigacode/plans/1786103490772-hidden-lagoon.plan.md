# План реализации: Tool Calling / Function Calling Agent

## Цель
Полноценный AI-агент для бронирования авиабилетов с Tool Calling, поддерживающий:
- Поиск рейсов, проверку доступности, бронирование
- Конвертацию валют
- Погоду в городе назначения
- Веб-интерфейс с графиком выполнения (LangGraph Studio format)
- Подключение к реальным API с fallback на mock

## Архитектура

### 1. Модули инструментов (`tools/`)
```
tools/
├── __init__.py
├── base.py          # Базовый класс Tool с real/mock режимом
├── flight.py        # FlightBookingTool (search, check, book)
├── currency.py      # CurrencyConversionTool (get_rate, convert)
└── weather.py       # WeatherTool (get_weather)
```

### 2. Агентский цикл (`agent.py`)
- LangGraph StateGraph с узлами: agent → tools → agent → ...
- System prompt с описанием инструментов
- Fallback на mock при недоступности LLM/Real API
- Цепочка: search_flights → check_availability → get_weather → get_currency → book_flight

### 3. Веб-интерфейс (`web/`)
```
web/
├── __init__.py
└── app.py           # FastAPI + LangGraph Studio UI
```

### 4. API (`api/`)
```
api/
├── __init__.py
└── routes.py        # REST endpoints
```

### 5. Конфигурация (`config.py`)
- Настройки LLM (LM Studio)
- Настройки API ключей
- Toggle real/mock режимы

## Верификация
1. `uv run python -c "from agent import run_agent; print(run_agent('Забронируй билет из Москвы в Дубай на 10 августа для Иванова Ивана, эконом класс'))"`
2. Запуск API: `uv run python api/routes.py`
3. Запуск веб-интерфейса: `uv run streamlit run web/app.py`
